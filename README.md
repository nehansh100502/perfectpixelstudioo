# Perfect Pixel Studio 🌐

Perfect Pixel Studio is a **responsive business website** built using **HTML, CSS, and JavaScript** and deployed on a live hosting environment.

🌐 **Live Website:** https://perfectpixelstudioo.com/

This project focuses on clean UI design, responsive layouts, and real-world website deployment.

---

## ✨ Features

- Fully responsive design
- Clean and modern UI
- Multi-section layout (Home, Services, Team, Clients, Reviews, Contact)
- Optimized images and assets
- Deployed on live hosting

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
